# TC-01 升级安装并清理遗留配置

## 用例目标

验证在已经安装 rc5 旧版 `cronjob-frontend` 的集群上，执行新 `cronjob` 集群镜像升级后：

- 旧 `cronjob-frontend` namespace 被删除。
- 旧 Helm release `cronjob-frontend` 不再存在。
- 旧 values 路径迁移到 `apps/cronjob/cronjob-values.yaml`。
- 当前 Helm release 名称、namespace、Deployment、Service、Ingress 均为 `cronjob`。

## 关联代码修改

- `deploy/cronjob-entrypoint.sh`
  - `delete_legacy_cronjob_frontend` 删除旧 Helm release 和旧 namespace。
  - 迁移 `/root/.sealos/cloud/values/core/cronjob-frontend-values.yaml` 到 `/root/.sealos/cloud/values/apps/cronjob/cronjob-values.yaml`。
  - `adopt_namespaced_resource` 和 `adopt_cluster_resource` 接管已有资源，避免升级时 Helm ownership 冲突。
- `deploy/charts/cronjob/*`
  - 新 chart 统一使用 `cronjob` 命名。

## 前置条件

- <TEST_NODE> 已完成 Sealos Pro rc5 从 0 安装。
- 管理端附加包已安装。
- 基线中存在旧 `cronjob-frontend` namespace 和 workload。

## 测试流程

1. 在远端检查升级前基线：
   - `helm list -A | grep cronjob`
   - `kubectl get ns cronjob-frontend`
   - `kubectl get all,cm,ingress -n cronjob-frontend`
2. 执行首轮新应用升级：
   - `sealos run ghcr.io/sealos-apps/cronjob/cronjob-cluster:sha-99799cd`
3. 检查当前 Helm release：
   - `helm status cronjob -n cronjob`
4. 检查旧 namespace、旧 Helm release、旧 values 路径：
   - `kubectl get ns cronjob-frontend`
   - `helm status cronjob-frontend -n cronjob-frontend`
   - `find /root/.sealos/cloud/values -name '*cronjob*'`
5. 后续修复镜像 `sha-3aa827c` 升级后再次检查相同项目。

## 期望结果

- `cronjob` release 状态为 `deployed`。
- `cronjob` namespace 中 Deployment 为 `1/1`。
- `cronjob-frontend` namespace 不存在。
- `cronjob-frontend` Helm release 返回 `release: not found`。
- values 只保留在 apps 路径。

## 实际结果

通过。

- 升级前存在 `namespace/cronjob-frontend`、`deployment.apps/cronjob-frontend`、`service/cronjob-frontend`、`ingress/cronjob-frontend`。
- 升级后当前 release 为 `cronjob`，namespace 为 `cronjob`，Deployment 镜像为 `ghcr.io/sealos-apps/cronjob/cronjob:sha-99799cd`。
- 修复镜像复测后 release revision 为 2，Deployment 镜像为 `ghcr.io/sealos-apps/cronjob/cronjob:sha-3aa827c`。
- 旧 Helm release 返回 `Error: release: not found`。
- 旧 namespace 查询为空。
- values 路径为 `/root/.sealos/cloud/values/apps/cronjob/cronjob-values.yaml`。
