用例：TC-02 修复前页面创建失败复现
时间：2026-05-30 Asia/Shanghai
目标环境：脱敏后的单节点 Sealos 测试集群
镜像：ghcr.io/sealos-apps/cronjob/cronjob-cluster:sha-99799cd

测试步骤：
1. 打开 Sealos Desktop。
2. 打开“定时任务”应用。
3. 在空列表页面点击“添加定时任务”。

实际结果：
1. 页面没有进入创建表单。
2. 页面仍停留在空列表。
3. 浏览器侧出现 PAGEERROR Object。
4. Sealos Desktop 返回 function is not declare，说明当前 Desktop 没有暴露 account.getWorkspaceQuota。

判定：
失败，用例复现成功，需要增加旧 Desktop quota 接口兼容处理。
